# Animations

Анимация `StatsView` последовательно раскрывает сегменты и одновременно поворачивает их
на 360 градусов. Каждый следующий сегмент начинает заполняться только после предыдущего.
Текст с итоговым процентом остаётся неподвижным.

Тип заполнения выбирается в XML:

```xml
app:animationType="parallel"
```

или:

```xml
app:animationType="sequential"
```

или двусторонний:

```xml
app:animationType="bidirectional"
```
