# Custom Views

`StatsView` принимает абсолютные значения и самостоятельно рассчитывает долю каждого сегмента:

```kotlin
stats.data = listOf(500F, 500F, 500F, 500F)
```

По умолчанию сумма значений считается за 100 %. Для отображения незаполненной части можно задать
общий объём шкалы:

```kotlin
stats.maxValue = 2_000F
stats.data = listOf(500F, 500F, 500F) // заполнено 75 %
```
